# Requisitos do Projeto

## Objetivo
Criar uma plataforma de aprendizado interativa para redes de computadores.

## Funcionalidades esperadas
- Landing page profissional
- Dashboard do aluno
- Trilha de aprendizado
- Aulas por módulo
- Quiz e desafios
- Laboratórios interativos
- Glossário técnico
- Navegação em interface moderna

## Público-alvo
- Iniciantes em TI
- Estudantes de redes
- Pessoas interessadas em infraestrutura e suporte

## Tecnologias
- Next.js
- React
- TypeScript
- Tailwind CSS
- SQLite
