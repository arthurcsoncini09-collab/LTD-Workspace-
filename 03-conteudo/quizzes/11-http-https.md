# Quiz — Módulo 11 — HTTP/HTTPS

## 1. Qual método HTTP é usado normalmente para enviar dados de um formulário de login?

- GET
- **POST** ✅
- DELETE
- HEAD

**Explicação:** POST envia dados no corpo da requisição; GET colocaria a senha na URL.

## 2. O código 301 indica:

- Sucesso
- **Redirecionamento permanente** ✅
- Recurso não encontrado
- Erro interno do servidor

**Explicação:** 301 Moved Permanently informa que o recurso mudou de endereço definitivamente.

## 3. Um erro 503 indica que:

- O usuário não está autenticado
- **O servidor está temporariamente indisponível** ✅
- A página não existe
- O pedido foi aceito

**Explicação:** 503 Service Unavailable aparece em sobrecarga ou manutenção.

## 4. O que garante que você está falando com o servidor legítimo em uma conexão HTTPS?

- O endereço IP
- **O certificado digital assinado por uma CA confiável** ✅
- A porta 443
- O cookie de sessão

**Explicação:** O certificado vincula a chave pública ao domínio e é validado pela cadeia de confiança.

## 5. O cabeçalho HSTS serve para:

- Comprimir respostas
- **Forçar o navegador a usar apenas HTTPS no domínio** ✅
- Definir o tempo de cache
- Autenticar o usuário

**Explicação:** Strict-Transport-Security evita ataques de rebaixamento para HTTP.

## 6. Qual versão do HTTP roda sobre QUIC?

- HTTP/1.0
- HTTP/1.1
- HTTP/2
- **HTTP/3** ✅

**Explicação:** O HTTP/3 usa QUIC, que roda sobre UDP.
