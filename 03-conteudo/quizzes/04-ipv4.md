# Quiz — Módulo 4 — IPv4

## 1. Quantos bits tem um endereço IPv4?

- 16
- **32** ✅
- 64
- 128

**Explicação:** IPv4 tem 32 bits (4 octetos de 8 bits). O IPv6 tem 128.

## 2. Qual destes é um endereço privado (RFC 1918)?

- 8.8.8.8
- **172.20.5.1** ✅
- 200.10.10.1
- 172.32.0.1

**Explicação:** A faixa privada 172.16.0.0/12 vai de 172.16.0.0 a 172.31.255.255.

## 3. Um computador com IP 169.254.33.7 provavelmente:

- Está com IP público
- **Não conseguiu obter IP via DHCP** ✅
- Está em uma VPN
- É um servidor DNS

**Explicação:** 169.254.0.0/16 é APIPA: o sistema se autoatribui esse endereço quando o DHCP falha.

## 4. Qual a máscara decimal de um /26?

- 255.255.255.0
- 255.255.255.128
- **255.255.255.192** ✅
- 255.255.255.224

**Explicação:** 26 bits 1: o último octeto é 11000000 = 192.

## 5. Qual o endereço de rede de 192.168.10.130/26?

- 192.168.10.0
- **192.168.10.128** ✅
- 192.168.10.130
- 192.168.10.192

**Explicação:** Blocos de 64 no último octeto: 0, 64, 128, 192. O 130 cai no bloco 128.

## 6. O que acontece quando o TTL de um pacote chega a zero?

- Ele é enviado em broadcast
- **Ele é descartado** ✅
- Ele volta para a origem
- O TTL é reiniciado

**Explicação:** O roteador descarta o pacote e normalmente envia um ICMP Time Exceeded à origem.
