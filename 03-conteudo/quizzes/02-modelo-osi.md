# Quiz — Módulo 2 — Modelo OSI

## 1. Em qual camada do modelo OSI o protocolo IP opera?

- Camada 2
- **Camada 3** ✅
- Camada 4
- Camada 7

**Explicação:** O IP é o protocolo de endereçamento lógico e roteamento da camada de Rede (3).

## 2. Qual é a PDU da camada de Enlace?

- Bits
- Pacote
- **Quadro** ✅
- Segmento

**Explicação:** Na camada 2 a unidade de dados é o quadro (frame), com cabeçalho MAC e trailer FCS.

## 3. Criptografia e codificação de caracteres são funções associadas a qual camada?

- Sessão
- **Apresentação** ✅
- Transporte
- Rede

**Explicação:** A camada 6 trata formato, codificação, compressão e criptografia dos dados.

## 4. Um switch tradicional toma decisões de encaminhamento com base em:

- Endereço IP
- Número de porta TCP
- **Endereço MAC** ✅
- Nome de domínio

**Explicação:** O switch é um dispositivo de camada 2 e usa a tabela de endereços MAC.

## 5. Durante o encapsulamento, qual camada adiciona um trailer (FCS) além do cabeçalho?

- **Enlace** ✅
- Rede
- Transporte

**Explicação:** A camada de Enlace adiciona o FCS (Frame Check Sequence) ao final do quadro para detectar erros.
