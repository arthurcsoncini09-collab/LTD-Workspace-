# Fluxos de Usuário

## Fluxo principal
- Home -> Dashboard -> Aprender/Trilha -> Aula -> Quiz -> Marcar como concluído -> Próximo módulo

## Fluxo de laboratório
- Labs -> Subnetting Lab -> Resolver passo a passo
- Labs -> Network Simulator -> Configurar IP -> Ping -> Diagnóstico do erro
- Labs -> Packet Journey -> Etapas -> "Estudar este tema" -> Aula
- Terminal -> Comando -> Saída simulada + explicação

## Fluxo de referência
- Busca global -> Resultados (módulos, aulas, glossário, labs) -> Conteúdo
- Glossário -> Busca -> Termo -> Definição técnica

## Fluxo de acompanhamento
- Progresso -> Percentual por módulo -> Módulo
- Dashboard -> Continuar de onde parou / Próximos módulos -> Aula
- Perfil -> Nível, estatísticas -> Reiniciar progresso

## Fluxo de avaliação final
- Desafios -> Desafio Final -> Requisitos e rubrica -> Checklist -> Dicas/Solução -> Prova final
