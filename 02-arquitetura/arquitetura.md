# Arquitetura do Projeto

## Visão geral
A plataforma utiliza Next.js com app router e banco SQLite para armazenar conteúdo pedagógico.

## Camadas
- Front-end: páginas, componentes, navegação
- Conteúdo: módulos, aulas, quizzes, glossário
- Dados: base local SQLite
- UX: interação, progressão, exercícios, laboratórios

## Fluxo
1. Usuário acessa a landing page
2. Navega pelos módulos e aulas
3. Consulta glossário e realiza quizzes
4. Acesse laboratórios e trilhas
5. Evolui no aprendizado
